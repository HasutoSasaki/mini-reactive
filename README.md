# ✨ mini-reactive

Vue.js のリアクティブシステムの仕組みを理解するための、ミニマムな実装プロジェクトです。

## 🎯 プロジェクトの目的

このプロジェクトは、Vue.js の中核となるリアクティブシステムの基本的な仕組みを理解することを目的としています。実際の Vue.js の実装をシンプルにした形で再現することで、リアクティブシステムの動作原理を学ぶことができます。

## 📁 プロジェクト構成

プロジェクトは以下の 2 つの主要なパッケージで構成されています：

### 🛠️ mini-reactive

Vue.js のリアクティブシステムのミニマム実装です。以下のファイルが含まれています：

- `app.js`: アプリケーションのメインロジック
- `index.html`: デモページ
- `lib/reactive.js`: リアクティブシステムの実装

### 🔍 proxy-sample

JavaScript の Proxy オブジェクトの基本的な使用方法を学ぶためのサンプルコードです。

- `sample1.ts`: Proxy の基本的な使用例

## 📚 使い方

各パッケージのサンプルコードを通じて、以下の内容を学ぶことができます：

1. JavaScript の Proxy の基本的な使い方
2. リアクティブシステムの基本的な仕組み
3. Vue.js がどのようにデータの変更を検知し、UI を更新しているか

詳細な解説やデモの実行方法については、各パッケージのディレクトリ内のファイルをご参照ください。
